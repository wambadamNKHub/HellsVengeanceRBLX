HellsUI Documentation

Welcome to the documentation for HellsUI.

HellsUI is a simple Roblox UI library designed to make creating windows, pages, buttons and toggles easier.

This documentation covers the basic functions currently available in the library.

Initializing the Library

Before creating a UI, you first need to load the HellsUI library. 

local HellsUI = loadstring(game:HttpGet(
    "https://raw.githubusercontent.com/wambadamNKHub/HellsVengeanceRBLX/refs/heads/main/HellsUI"
))()

This downloads and loads the HellsUI library.

Creating a Window

Once the library has been initialized, you can create the main UI window. 

local Window = HellsUI:CreateWindow({
    Title = "Hell's Vengeance v1"
})

Title

The Title property controls the text displayed at the top of the UI. 

Title = "Hell's Vengeance v1"

You can change it to whatever you want. 

Title = "My Custom Menu"

Creating Pages

Pages are used to organize buttons and toggles into different sections of your menu. 

local Main = Window:CreatePage("Main")

This creates a page named Main.

Pages are useful for separating different features such as Players, Weapons, Fun, Settings, etc.

Example

local Weapons = Window:CreatePage("Weapons")

local Players = Window:CreatePage("Players")

local Settings = Window:CreatePage("Settings")

Buttons

Buttons execute a function when the user clicks them.

Creating a Button

Main:CreateButton("Test Button", function()
    print("Test button!")
end)

Button Name

The first argument controls the text displayed on the button. 

Main:CreateButton("My Button", function()

end)

Button Callback

The function after the button name is called whenever the button is clicked. 

Main:CreateButton("Print Message", function()
    print("Hello!")
end)
Clicking the button above would execute the callback and print Hello!.

Toggles

Toggles are useful for features that can be turned on and off.

Creating a Toggle

Main:CreateToggle("Test Toggle", false, function(enabled)
    print("Toggle:", enabled)
end)

Arguments

A toggle takes three main arguments: 

CreateToggle(
    "Toggle Name",
    false,
    function(enabled)

    end
)
  • Toggle Name — Text displayed next to the toggle.
  • false — The default state of the toggle.
  • Callback — Function executed whenever the toggle changes.

Default Enabled

Setting the second argument to true starts the toggle enabled. 

Main:CreateToggle("God Mode", true, function(enabled)

end)

Checking the State

Main:CreateToggle("Funny Mode", false, function(enabled)

    if enabled then
        print("Funny Mode enabled!")
    else
        print("Funny Mode disabled!")
    end

end)

Subpages

Pages can also be created from another page. This allows you to create a page hierarchy. 

local Main = Window:CreatePage("Main")

local Fun = Main:CreatePage("Fun")

In this example, Fun is created from the Main page.

Adding Features to a Subpage

local Fun = Main:CreatePage("Fun")

Fun:CreateButton("Option 1", function()
    print("Option 1")
end)

Fun:CreateToggle("Funny Mode", false, function(enabled)
    print("Funny Mode:", enabled)
end)
Subpages are useful when a page contains many related options and you want to keep the main menu organized.

Full Example

Here is everything combined into one simple example. 

local HellsUI = loadstring(game:HttpGet(
    "https://raw.githubusercontent.com/wambadamNKHub/HellsVengeanceRBLX/refs/heads/main/HellsUI"
))()


local Window = HellsUI:CreateWindow({
    Title = "Hell's Vengeance v1"
})


local Main = Window:CreatePage("Main")


Main:CreateButton("Test Button", function()
    print("Test button!")
end)


Main:CreateToggle("Test Toggle", false, function(enabled)
    print("Toggle:", enabled)
end)


local Fun = Main:CreatePage("Fun")


Fun:CreateButton("Option 1", function()
    print("Option 1")
end)


Fun:CreateToggle("Funny Mode", false, function(enabled)
    print("Funny Mode:", enabled)
end)
